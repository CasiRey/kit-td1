# Prompts d'aide au code

Le cours accepte le code écrit avec l'aide d'une IA, à condition de garder dans le dépôt les prompts utilisés, tels qu'ils ont été écrits. Chaque membre qui a utilisé une IA ajoute ici un fichier à son nom.

| Fichier | Membre | Outil |
|---|---|---|
| [yohann-claude-code.md](yohann-claude-code.md) | Yohann | Claude Code (Claude Opus 5.5) |
| pas encore dans le dépôt | Simon | Claude, déclaré dans [notes/analyse-role-E.md](../notes/analyse-role-E.md) pour les scripts d'`outils/` et la lecture des SQL en échec |

Règle commune : aucune valeur de référence ne vient d'une réponse d'IA. Les références sont des requêtes SQL exécutées sur la base, vérifiées de façon indépendante et validées par l'encadrant. Tout code produit avec une IA a été exécuté et vérifié ; le sous-groupe en reste responsable.
